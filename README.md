### 🚀 Proyectos Destacados

#### 🎯 **SkillFest**
Plataforma de gestión de eventos estructurada en arquitectura de capas descolada.
* **Backend:** [Proyecto-Eventos-API](https://github.com/Carlpdev20/Proyecto-Eventos-API.git) — API RESTful con Spring Boot, JPA, Hibernate, **Spring Security y JWT**.
* **Frontend:** [Proyecto-Eventos-FRONT](https://github.com/Carlpdev20/Proyecto-Eventos-FRONT.git) — Interfaz SPA desarrollada en React con consumo de servicios asíncronos.

#### 📱 [FamLink](https://github.com/Carlpdev20/Famlink.git)
Ecosistema multiplataforma para la gestión y asignación de dinámicas familiares.
* **Web:** Backend desarrollado en Java con Spring Boot y MySQL.
* **Mobile:** Aplicación móvil nativa en Kotlin para Android con integración a Firebase.

#### ⚙️ [NexaCore](https://github.com/Carlpdev20/NexaCore-Sistema-Asistencia.git)
Sistema web empresarial para la gestión y control de asistencia laboral.
* **Backend:** C# con **.NET Core** bajo patrón arquitectónico **MVC**.
* **Base de Datos:** Persistencia estructurada sobre SQL Server.
