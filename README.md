### 📁 Proyectos Destacados

#### 🏆 [SkillFest](https://github.com/CarlDev10/SkillFest)
Plataforma integral desarrollada con un enfoque robusto en el backend, alta seguridad y una interfaz dinámica.
* **Backend:** Diseñado bajo una estricta **arquitectura de capas** utilizando Java con Spring Boot y JPA.
* **Seguridad & APIs:** Implementación de servicios RESTful protegidos de extremo a extremo mediante **Spring Security y JWT** (JSON Web Tokens).
* **Frontend & DB:** Conectado eficientemente a una base de datos MySQL y un entorno frontend en React.

#### 👥 [FamLink](https://github.com/CarlDev10/FamLink)
Ecosistema digital multiplataforma diseñado para conectar usuarios tanto en la web como en entornos móviles de manera fluida.
* **Apartado Web:** Backend desarrollado por completo en Java con Spring Boot.
* **Apartado Mobile:** Aplicación móvil nativa construida para el sistema operativo Android.

#### ⚙️ [NexaCore](https://github.com/CarlDev10/NexaCore)
Aplicación web empresarial enfocada en un alto rendimiento, modularidad y facilidad de mantenimiento.
* **Backend & Lenguaje:** Desarrollado en C# aprovechando la potencia de .NET Core.
* **Estructura:** Implementado bajo el patrón arquitectónico **MVC** (Model-View-Controller) para una separación limpia de responsabilidades.
